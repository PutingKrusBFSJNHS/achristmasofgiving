# A Christmas Of Giving

A web application designed for Grade 10 - Puting Krus to showcase their Christmas short film, photo gallery, custom audio player with a real-time visualizer, and project credits.

## How to Run

1. Clone the repository to your local machine.
2. Ensure the `images/` and `music/` directories contain your media files.
3. Open `index.html` directly in any standard web browser.

---

## Customization Instructions

### 1. Facebook Video Embed
In `index.html`, locate the `<section class="video-section">` tag and set the `src` attribute of the `<iframe>` element to your embedded Facebook video link.

### 2. Gallery Images
Add your project photos to the `images/` folder, then update the `src`, `alt`, and `<figcaption>` elements inside the `<figure class="gallery-item">` tags in `index.html`.

### 3. Audio Tracks
Place your `.mp3` files in the `music/` folder and update the `data-src` and `data-title` attributes on the track buttons inside the `#music` section.

### 4. Credits Section
Replace the `[Name]` placeholders inside `<p class="credits-name">` elements with the actual names of your classmates, advisers, and contributors.
